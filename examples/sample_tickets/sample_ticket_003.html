BACnet IP cihaz T3000'de offline görünüyor

Ticket No: T3K-2024-0033 | Durum: Resolved | Öncelik: High

Oluşturma: 2024-07-11 | Çözüm: 2024-07-11 (aynı gün)

Problem

3. kattaki AHU-5 BACnet/IP cihazı T3000 Device List'te "offline" (gri) gözüküyor. Ping atılabiliyor (192.168.14.52 cevap veriyor), yani network katmanı OK. Wireshark'ta BACnet trafiği var ancak T3000 WhoIs broadcast'lerine I-Am cevabı gelmiyor sadece bu cihazdan. Diğer AHU'lar (AHU-1..4) normal.

Çözüm

AHU-5'in Device Instance ID'si 1050050 yanlışlıkla başka bir cihazla (chiller controller 1050050) aynıydı. BACnet'te Device Instance ID network çapında benzersiz olmak zorunda. Çakışma durumunda:

  1. BACnet Discovery Tool (Yabe veya VTS) ile network tara
  2. Aynı Device Instance ID'yi iki farklı IP'den gösteren cihazı bul
  3. AHU-5'in local HMI'ından Device Instance'ı 1050052'ye değiştir
  4. Cihazı reboot et (BACnet reset komutu)
  5. T3000'de "Rediscover devices" yap

Cihaz 90 saniye içinde online geldi, trending ve komutlar normal çalışıyor.

Not: IT grubunun kullandığı IP envanterinde BACnet Device Instance kaydı yoktu. Yeni cihaz devreye alınırken T3000 projesinde kullanılan Device Instance Registry'ye eklenmesi SOP'a yazıldı.

Yorumlar

[Teknisyen] Çakışma T3000 tarafında Discovery Conflict log'unda da görünür ama default olarak kapalı. Enable etmeyi öneririm.
